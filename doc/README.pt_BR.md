## 📱 Descrição

Tomoko é uma interface de streaming livre e de código aberto para serviços populares de vídeo e áudio. Ele fornece uma experiência limpa, privada e sem anúncios, sem necessidade de contas.

Construído em Kotlin Multiplatform, o Tomoko roda em Android, desktop e iOS com um código compartilhado.

### ✨ Recursos

- 🎥 Assistir vídeos em resoluções de até 4K
- 🎧 Áudio em segundo plano, carregando apenas o fluxo de áudio para economizar dados
- 🪟 Modo Picture-in-Picture (player flutuante)
- 📡 Suporte a transmissões ao vivo
- 📝 Mostrar/esconder legendas/closed captions
- 🔍 Buscar vídeos, áudios, canais, playlists e álbuns
- 📺 Inscrever-se a canais (sim, mesmo sem estar logado em qualquer conta!)
- 🔔 Receba notificações sobre novos vídeos de canais em que você está inscrito
- 📥 Baixe vídeos/áudios/legendas
- 🎵 Múltiplos serviços: YouTube, PeerTube, Bandcamp, SoundCloud
- 🌓 Dark mode com suporte a Material You
- 🎨 Interface Material Design 3 no estilo Pixel

## 📦 Instalação

Instale o Tomoko via:

1. **GitHub Releases** — Baixe o último APK
2. **Build from source** — Clone e compile com Gradle
